# Image Assets

The public form uses the artwork in `products/`.

Keep these filenames if you want to replace the artwork without editing code:

- `products/ppec-logo.png`
- `products/explorers-card.png`
- `products/curiosity.png`
- `products/ppec-pride-logo.png`

The `reference/` folder contains earlier badge photos from the planning chat. They are not required by the app, but they are included as temporary reference material.
